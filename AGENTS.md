# Product language

GiftPortals uses English throughout the product. Keep application-owned UI,
navigation, accessibility labels, validation, errors, examples, assistant drafts,
photo descriptions, sourced-detail summaries, and new product documentation in
English. Browser or device locale must not select another language for these
outputs. English is the default spoken-input language.

Preserve the user's own photos, stories, names, and reviewed transcripts.
Explicit spoken-input language choices may remain available with English labels.
Keep official place names, source URLs, license notices, and accurately attributed
source titles intact. Do not rewrite existing private gifts merely to change
their language.

Verify English defaults using a Portuguese browser locale when changing the
creator, assistant, voice input, or language selection.
