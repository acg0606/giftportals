# GiftPortals design

The visual language is an original poetic travel journal: thin dark ink, generous space and warm sand, coral, turquoise, lilac and sky tones. Souvenirs sit within quiet illustrated environments, with a distinct gift-box reveal and a contemplative train transition. No existing artist's characters or compositions are copied.

Mobile portrait is the primary layout. Every primary action has a visible English label. Focus, keyboard navigation and readable contrast take precedence over decorative motion. Color is complemented by text and symbols for visit states. Illustrative map nodes are schematic, not administrative polygons.

The landing page should make the product understandable before entering a world: photograph → story → explorable gift. Creation, original photo, artistic reconstruction, sharing and collection are distinct steps. A recipient never needs to understand API terminology to open a box.

The object viewer supports rotate and zoom with an original-photo fallback. Generated environments explain their artistic nature in plain language. Audio starts only after a user gesture. The train lasts about ten seconds, offers immediate skip and honors reduced-motion preferences. Timers, animation loops, controls, observers, geometry, materials and textures are released on navigation.

Demo memories are explicitly fictional. Failure messages preserve the original memory and explain an actionable retry without suggesting that absent geometry was generated.
