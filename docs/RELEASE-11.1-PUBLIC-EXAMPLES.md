# GiftPortals 11.1 — owner-authorized public examples

Two completed gifts from Praça Américo Portugal Gouvêa were published as
public examples with the owner's explicit authorization on October 5, 2026.
The purpose is to let visitors explore these existing memories while new
World Labs generation is limited by the remaining provider credits.

This release reuses the already generated photographs, souvenirs, spatial
worlds and related delivered media. The public archive holds independent
copies, separate from the owner's browser collection and the original
private gift's retention. The existing read-only gallery supplies fresh signed
media URLs without exposing creator capabilities, provider credentials, private
job state or retry controls.

The authorized import is limited to these two gifts. Their approved names,
stories and original photographs are preserved. Other private gifts are not
published by this operation, and the creator's existing unchecked public
publication consent remains unchanged for future gifts.

No Tripo or World Labs generation or retry was submitted for this import.
Copying and verifying the existing assets consumed no provider generation
credits. The recorded reserved totals remained **1,100 Tripo credits** and
**23,700 World Labs credits**; these totals are not current provider balances.
