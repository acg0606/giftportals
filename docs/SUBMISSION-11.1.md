## Project description

Some gifts fit in your hand. Others take you to an entire world.

GiftPortals turns a place photograph and personal words into a memory someone can open in their browser. Tripo creates a textured 3D keepsake; World Labs creates a spatial interpretation of the place. The sender's original photograph, story and dedication stay beside the generated gift.

Version 11.1 opens a shared memory desk without login. New creations require separate, explicit approval to publish the original photo, names, words and delivered media. Gifts enter the public collection only after their actual outputs are copied and verified in an independent cloud archive. Two owner-authorized memories from Praça Américo Portugal Gouvêa now join the public examples, reusing completed assets with no new provider generation.

Open a keepsake, rotate it and inspect its details, then enter its world. A 30-second automatic arrival leads to a memory newspaper containing the original photo, words, dedication and souvenir reference. Close the newspaper to explore where the generated collision mesh supports movement. Reduced motion or unsupported geometry opens a still view and the newspaper.

The photographic Paris and Rio examples use credited source photographs and real delivered provider assets. Paris/Rio keepsakes reuse earlier miniature assets; their new source photos generated the worlds. Generated surroundings infer unseen areas; they are spatial interpretations, not measured reconstructions. Example names and stories are illustrative; the Praça gifts preserve their owner's approved originals.

Optional print preparation exports the original GLB and a scaled STL/ZIP with mesh diagnostics. Blueprint import, repair, supports, slicing, physical printing and headset validation remain unverified. The recorded walkthrough shows completed gifts; provider generation takes time and is not presented as instant.

## Tripo contribution

Tripo is a core creation engine: an approved photo or derived keepsake reference produces a textured GLB keepsake. GiftPortals preserves the delivered mesh for orbit, detail zoom, mobile texture variants and optional GLB/STL preparation. The keepsake accompanies the original photograph, sender's story and World Labs world in a browser gift. Version 11.1 reuses the two owner-authorized Praça souvenirs; opening them spends no generation credits.

## World Labs contribution

World Labs/Marble supplies actual SPZ worlds, panoramas and collider meshes, plus the generated Daylight memory desk. Three.js/Spark render the scenes; Rapier uses the original collider for supported exploration. Version 11 adds a 30-second automatic arrival and memory newspaper. Paris and Rio use photographic references with inferred unseen surroundings. Version 11.1 archives two completed Praça worlds without generating replacements.
