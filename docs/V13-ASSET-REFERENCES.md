# V13 original inspiration artwork

The selectable references are original artistic interpretations. They are not photographs, verified archaeological replicas, engineering drawings, or surveyed geography. Historical facts are separate, reviewed, sourced cards in `shared/gift-curiosities.ts`.

The built-in image generation tool created nine selected gift assets plus an observatory scene reference. Rio reuses the previously generated and reviewed Rio panorama. Final JPEGs live in `public/assets/examples/v13/`; no runtime image depends on an external asset URL.

All generated prompts use `stylized-concept`, GiftPortals selectable reference / generation input, premium detailed travel or museum imagery, no people, no text, no watermark. Scenes request a visible ground plane and distinct foreground, middle distance and background. Object references request the complete isolated silhouette on a pale ivory background for Tripo.

An extra daylight Paris variation was explored during safety diagnostics. It is not the selected asset. The selected blue-hour image must pass the active local safety gate before either provider receives it.

City presets preserve the original scene for World Labs and derive a framed keepsake for Tripo. Object presets send the object reference to Tripo and describe a separate, related imaginative environment to World Labs. A source object photo cannot by itself authenticate the history of an object.
