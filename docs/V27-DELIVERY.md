# GiftPortals V27 — local validation, cloud prepared

## Delivered behavior

- A warm cream, peach, lilac and mint interface connects Home, the creator, gifts, journals and the **Memory desk**. The collection is an original procedural 3D desk with a softly reflective window, books, laptop, lamp, plants and a central keepsake inside a transparent pastel projector. This browser visual is not Jupiter SR hardware integration.
- **Three complete asset-backed gifts:** Rio, Paris and Antikythera. All use the approved first-person walking controls, their own transformed collider/metric scale and physically audited viewpoints. Ten city/object photographs remain inspiration choices, not ten completed worlds. New completed gifts use the same pipeline when their actual collider supports a safe spawn and nearby paths; unsupported geometry does not receive an invented floor.
- Untie the ribbon, lift the lid and reveal the real Tripo keepsake. Each gift retains its personal story in a newspaper, book or tablet. The bright painted scenery, low warm sun, haze and subtle motes are original client-side atmosphere. Existing GLB textures and cached World Labs SPZ assets were reused, not regenerated. New world prompts and the existing place-souvenir reference stage now request the luminous oil-painted style; direct object-photo reconstruction does not guarantee painted texture.
- Local print preparation exports the unchanged color GLB, an actual mesh STL sized 40–150 mm and a ZIP with hashes and geometry diagnostics. All three real meshes passed the offline export audit, but have diagnostic edges requiring review. Blueprint import, repair, orientation, supports, wall thickness, slicing and a physical print remain untested.
- Optional **View in VR** opens a separate WebXR panel for the current authorized GLB. Only an explicit Enter headset action requests a supported secure-context immersive VR session. Accepted sessions display the actual keepsake; a controller ray hitting it can rotate it. Unsupported browsers retain the ordinary gift. PICO device/controller behavior, comfort and performance require a real headset test; no PICO hardware session, AR or passthrough is claimed.
- The cloud creator has browser transport, durable private jobs, consent/moderation gates, hashed signed uploads, capability links, leases, idempotency, persistent budgets/quotas and retention. Supported cloud browsers offer editable browser dictation with disclosure that their speech service may process audio. Audio-file transcription remains local; typing remains available.

A late parallel collection update added fixed local PBR wood textures and neutral reflective finishes. It was preserved and rechecked in the final 708-test run; earlier desk/refinement reports document the prior painted room. The final runtime uses the modern desk pictured in `desk-final.png`. See V27-PARALLEL-DESK-AUDIT.md for the inspected resource limits.

## Local verification

The final application suite passed **708 tests across 69 test files**, with zero failures, cancellations or skipped tests. Strict client/server TypeScript, the production Vite build and offline cloud preflight passed, including the applied XR files. Vite reports large lazy Three/Spark/Rapier/Cesium chunks; this is a build warning and a real mobile loading/performance consideration.

Fifteen additional behavioral SQL checks ran against the repaired migration in isolated PostgreSQL 18.3 WASM. This does not establish live Supabase Storage/PostgREST behavior or multi-connection contention. Real-collider tests cover the three cached worlds. Local browser QA covered the warm desk/package, the Photo → Place (skip GPS) → Story → Review path and Home at 375/390 px without horizontal overflow. Actual short strolls covered 10.442 m in Antikythera, 10.213 m in Rio and 10.198 m in Paris, with valid grounded collision states and their tablet/newspaper/book readers. Portrait movement/action controls did not overlap. Desktop VR unavailability retained the ordinary canvas and allocated no XR canvas. Product captures are retained in the local V27 evidence folder; see V27-BROWSER-VALIDATION.md for observation limits. No new paid generation was submitted.

Two browser observations remain explicit:

1. One prior Spark 2.1.0 unhandled promise appeared during HMR/world-route teardown. Read-only vendor inspection identified asynchronous teardown paths as a possible cause, without a captured stack proving it. No vendor promise fix or version upgrade was applied; offline renderer fixtures do not certify GPU teardown.
2. IAB automation timed out after 20 seconds for both the ZIP download event and download helper. Actual file completion is unconfirmed. The native ZIP link, package tests and export of all three actual meshes passed locally; those results do not prove that automated browser download completed.

## Cloud activation and public delivery

The project is **prepared for Vercel and Supabase, not deployed or published**. Generation defaults off and database budgets default to zero. The chosen target still needs migrations, private buckets/signed-upload validation, an independently validated moderation service, exact origin/secrets, provider limits and explicit spend/storage caps. Node/pnpm installation and Vercel-specific function bundling have not been exercised on that target. Legacy localhost filesystem/Python APIs do not supply remote creation.

Prepared uploads expire after two hours; finalized photos/gifts expire seven days after finalization. Signed media URLs last one hour and refresh when the gift reopens.
