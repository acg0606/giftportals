Prioritize one complete interaction across both sponsors: enter a Marble world, discover the actual Tripo souvenir, inspect it and open its personal story, then return to the gift/collection. ## Three concrete integrations

1. **Souvenir discovery inside every walking gift — first priority.** Place the existing Tripo GLB at an audited, reachable location in its Marble environment. Add inspect/open-story actions, bounded pickup/place only if useful, and a simple physical proxy independent of render geometry. Share the gift's real story and existing object asset across the walk and room. Calibrate from each world's metadata and transformed collider; expose only reachable viewpoints. Upgrade Spark in an isolated saved baseline, then validate repeated enter/exit, paused rendering, keyboard/touch controls, mobile memory and the 100k fallback. New World Labs generation cost: **zero when using existing files**; hosting/storage and development costs remain. Official Spark/Rapier examples establish technical feasibility, not product implementation. [Examples](https://docs.worldlabs.ai/api/interactive-world-examples), [Spark releases](https://github.com/sparkjsdev/spark/releases).

2. **Multi-view memory creation — second priority.** Promote the tested operator contract into an optional creator input: same-place overlapping photographs with known direction when available, or one genuine panorama. Preserve originals, moderate every image, show the input/model before one intentional paid submission, and retain operation IDs/unknown reservations. Keep 1.1 standard as the predictable choice; offer Plus only with its full maximum reserved and a demonstrated benefit. Compare the resulting gift against the single-image baseline using the same walk/collider audit. This could improve identity and spatial consistency, but is not a surveyed reconstruction guarantee. [Multi-image guidance](https://docs.worldlabs.ai/marble/create/prompt-guides/multi-image-prompt), [API inputs](https://docs.worldlabs.ai/api/world-generation-examples).

3. **Layout-guided gift garden — bounded experiment.** Build an original simple layout with an accessible floor, short paths and a Tripo display pedestal; render a 2:1 depth panorama; call the public `pano:depth_to_rgb` endpoint, then generate Marble from the resulting RGB panorama. PNG needs correct positive depth bounds; EXR uses floating depth. The appearance only approximately follows geometry, so validate the generated collider again. The endpoint's specific tariff was not located; do not infer price from its illustrative `123` cost field or enable it until the cost is established. This is an optional new creation mode, not a repair of existing worlds. [Depth-to-RGB API](https://docs.worldlabs.ai/api/reference/pano/depth_to_rgb), [official sample](https://github.com/worldlabsai/worldlabs-api-examples/tree/main/web-chisel-depth-png).

## Cost and operational envelope

Published API conversion: **1,250 credits = US$1**; API billing is separate from the Marble app. Totals below include panorama preparation. [Official pricing](https://docs.worldlabs.ai/api/pricing).

| Input | Marble 1.1 | Marble 1.1 Plus maximum |
| --- | ---: | ---: |
| Valid panorama | 1,500 / $1.20 | 3,000 / $2.40 |
| Text or ordinary image | 1,580 / $1.264 | 3,080 / $2.464 |
| Multi-image or video | 1,600 / $1.28 | 3,100 / $2.48 |

Plus actual cost varies. A new HQ mesh export costs 3,500 credits/$2.80 and produces both mesh variants; cached/in-progress exports are free. PLY splat export is free. Existing collider download and full-resolution GET reuse are distinct from requesting that paid HQ export. Depth-to-RGB pricing remains unknown; its subsequent pano-to-world stage uses the table above. [Pricing](https://docs.worldlabs.ai/api/pricing).

Default generation starts are approximately three/minute and sixty/hour per API account, with accepted jobs usually taking about five minutes. Approved higher throughput is not assumed. A confirmed 429 was not accepted and may be retried with backoff; an ambiguous submission must remain held, then recover its known operation rather than creating a duplicate. [Rate limits](https://docs.worldlabs.ai/api/rate-limits). Keep private provider permissions, safe durable asset mirroring, transactional quotas, bounded input/assets and persisted submission intent before opening public generation. No current balance or cloud readiness is established by this research.
