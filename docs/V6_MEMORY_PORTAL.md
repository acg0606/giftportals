# V6 — the gift becomes a doorway

The V5 studio made the assets legible, but a recipient had to switch tabs to discover why the object and world belong together. V6 adds one continuous encounter before the existing exploration loop.

## Demo beat

1. Open **Maya’s gift** from the home page. A real, previously generated Tripo GLB appears with its original fictional reference.
2. Select **Step inside this memory**. The object viewer is released and the attached World Labs panorama bridges into the actual SPZ environment.
3. Read Maya’s words: **“The physical gift can wait. This little world can arrive today.”** Select **Look around** to move the story card aside and explore the actual artistic environment; **Show story** brings it back. Close and Explore remain available.
4. Select **Explore the three fragments**. Explicitly reveal object, world and story, then make a session keepsake through the existing studio.

Direct entry: `#/trail?demo=recipient&memory=demo-perdizes-cup&portal=1`. The studio also exposes a portal entry on an authorized memory with both an attached model and non-image world.

## Scope and truth

Maya and Noah are fictional demo people. The original bird reference is AI-generated. The GLB and SPZ are actual completed provider outputs. The world is an artistic atmosphere, not a reconstruction of Perdizes. Opening the encounter does not generate anything or spend provider credits.

The encounter receives the selected entry from the current authorized catalog. It has no API write, claim, keep, location, camera or microphone action. Generic memories use their authorized author content; fixture-specific fiction is restricted to the exact public bird fixture. The encounter does not automatically reveal fragments or change physical visit history.

The native modal has an explicit exit and Escape support. Only one renderer is mounted at a time; route/account/scope changes invalidate late imports and callbacks. Original media, the full generated panorama, retry and readable loading/failure states remain available. Reduced-motion settings remove the cinematic transition.
