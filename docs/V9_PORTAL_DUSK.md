# Portal at dusk

The selected visual direction is concept 1, “Portal at dusk.” Its source is `exec-d1677caf-2b7a-4aac-bba5-d86bf33018c0.png` (853 × 1844). The welcome keeps the immersive Rio portal, dusk foliage, warm keepsake and cream typography. Heading, actions and navigation are real accessible HTML.

## Experience

1. **Get started** opens the anonymous Rio composer.
2. Name the memory and choose a feeling.
3. Add a recipient, sender, dedication and story. The gift changes while typing.
4. Review the gift and **Preview portal**. The artistic Rio panorama supports bounded looking around and a readable personal message.
5. Return to editing or explicitly **Save in this browser**. Resume restores that draft. Local preview links contain the text in the fragment and work on this device while the local server runs.

**Explore a gift** opens the fictional Rio example. **Sign in** remains optional. When the private service is unavailable, its dialog says so and allows continuing without an account. Existing configured email/password auth is preserved. Email OTP is not enabled: the provider's OTP template and actual email delivery have not been configured or verified. No SMS path is added.

## Assets

- `welcome-bg.webp`: AI-generated derivative of the selected mock, removing interface text and controls while preserving the physical scene. 853 × 1844, quality 95.
- `rio-keepsake.png`: AI-generated transparent product cutout aligned with that scene. 1254 × 1254 RGBA; alpha is supplied by the image generator.
- `brand-mark.png` and `brand-lockup.png`: unmodified raster crops from the selected source. No hand-drawn substitute.
- Inter variable font: [official author distribution](https://rsms.me/inter/), bundled locally under its included OFL license.
- Phosphor regular arrow, close, envelope and check assets: [official repository](https://github.com/phosphor-icons/core), bundled locally under its included MIT license.

Image generation produced visual assets only. It did not call Tripo or World Labs, spend their production credits or create a geographic reconstruction. The previously implemented artistic panorama and the separate provider-backed Studio remain available.

## Scope
