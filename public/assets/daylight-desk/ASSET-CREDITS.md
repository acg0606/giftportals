# Daylight atelier asset credits

Original GiftPortals artistic room, based on the user's selected built-in OpenAI ImageGen concept and cleaned reference. Generated by World Labs full Marble 1.0 on 4 October 2026, one paid request, 1,580 credits. Demo scenery and memories are fictional.

`provenance.json` records the source reference hash, actual paid accounting, sanitized recipe and all provider export hashes. `collider-calibration.json` records measurements of the actual collider after the export's Y-up conversion.

`shadow-receiver.glb` is an exact subset of that World Labs collider. It preserves original triangles, winding, vertices and node transforms. Runtime applies the same provider-to-Three flip once. It supplies shadow alpha only and creates no substitute desk or new tabletop plane. Its provenance contains the original source and derived hashes.

`lighting.webp` is a small equirectangular derivative of the preserved World Labs panorama, used only for PBR lighting. The visible environment is the actual SPZ room.

The three GLBs under `keepsakes/` derive from existing Tripo public examples. Embedded color and data textures were resized/re-encoded for mobile. All geometry buffers and scene/material structure remain unchanged; source originals remain intact. The adjacent provenance files and combined audit record hashes, bytes and texture dimensions. Existing independent Tripo photograph frame and journal retain their earlier asset credits.

Three.js/Spark render imported assets. Inter, Georgia/system serif and the existing licensed Phosphor icons provide interface typography and controls. Refer to the original font/icon license notices under `../portal-dusk/`.
