# GiftPortals 10.0 interface assets

- Caveat variable font: Google Fonts, [official source](https://github.com/google/fonts/tree/main/ofl/caveat), SIL Open Font License 1.1. Full license included as `Caveat-OFL.txt`.
- Inter variable font and GiftPortals brand mark: existing project assets under `/assets/portal-dusk/`; original project provenance applies.
- `hero.jpg`: completed TapNow raster artwork, original output 3072 × 1728, downloaded for the Release 10.0.0 homepage. Recorded provider balance: 200 → 140 credits (60-credit difference). Attribution is to TapNow because its UI showed inconsistent model naming. This image is not a Tripo model or World Labs 3D world. The balance difference is an observation, not a final per-task settled-cost receipt.
- Separate completed TapNow travel-studio artwork supplied the single-image reference for the current World Labs room. The recorded later balance was 68; no per-task cost is inferred from that balance alone. Attribution remains TapNow, and the raster reference remains distinct from the generated SPZ/collider assets below.
- `studio-reference-corrected.png`: Tripo image-to-image edit of the TapNow studio, replacing the blank laptop display with a colorful Mount Fuji travel photograph. Model `chat_image_2`, high quality, 3072 × 1728; successful task `3eb48799-7068-4357-b99d-db1f8826c88c`, actual cost 40 credits. An earlier terminal image-transfer failure is recorded privately and was not reused as a completed asset.
- `memory-studio.spz`, `memory-studio-mobile.spz`, `memory-studio-pano.png` and `memory-studio-collider.glb`: actual completed World Labs outputs conditioned on the corrected reference. World `5e2a19e0-5d07-418a-9398-9792ad51ae8d`, model `marble-1.1`, actual cost 1580 credits. Desktop uses 500k splats; mobile uses 100k. The panorama provides PBR lighting only, without a visible loading preview. Actual collider measurements calibrate the independent meshes to the desktop. File hashes, input provenance and calibration are in `memory-studio-provenance.json`.
- `props/brass-travel-frame.glb` and `props/leather-travel-journal.glb`: independent Tripo 3D assets generated using `v3.1-20260211`, detailed geometry and PBR textures, 50 credits each. The frame opens the gift gallery; the journal opens gift creation. Mobile variants retain the original geometry/materials/node transforms with smaller embedded textures, reducing their combined download from 20.95 MB to 3.57 MB. Individual task receipts, hashes, texture settings and derivation evidence are beside the assets under `props/`.
- `memory-studio-full.spz` belongs to the previous World Labs world `a986cafc-e5fa-42c7-a847-58b73a621ef6`. It remains historical output and is not loaded by the collection. Both generated studios are artistic interpretations of fictional reference artwork.
