# Sponsor-generated desk props

These two original assets were generated through the Tripo text-to-model API for GiftPortals on 2026-10-04, using `v3.1-20260211` with detailed geometry and PBR textures. Each GLB embeds base colour, metallic/roughness and normal maps at 4096 × 4096. Completed provider tasks recorded 50 credits each.

- `brass-travel-frame.glb`: brass-coloured travel photograph frame, including its rear support. The generated photo shows Fuji, a torii gate, cherry blossoms and a lake. The final composition is vertical.
- `leather-travel-journal.glb`: closed cognac leather journal with stitched edges, cream paper and a brass-trimmed pen.

Adjacent provenance JSON files record requested settings, authored prompts, completed-task charges and SHA-256 hashes. The task ledger and signed download links are kept private; original GLB metadata and resource names are retained. Both original GLBs passed binary, embedded-image, PBR-map and size validation. Their actual provider previews and final desktop/mobile viewport placement were reviewed. Runtime fitting uses the loaded bounds. Clicking the frame opens the gift collection; clicking the journal opens gift creation.

The `-mobile.glb` variants retain the exact source mesh buffer bytes, accessor definitions, material bindings and node transforms. Only embedded textures are reduced: opaque base colour remains JPEG at 1024 × 1024, while normal and metallic/roughness maps use lossless PNG encoding at 512 × 512. The combined mobile download is 3,570,956 bytes, compared with 20,948,460 bytes for the original pair. Alpha is preserved when present; these source images are opaque. Derived provenance includes the original and mobile hashes, texture dimensions and unchanged geometry buffer hashes. Optimization was entirely offline and consumed no additional credits.
